# Doki-Doki-Literature-Club-Rain-Clouds-Nintendo-Switch-
This port was not made by me, it was created by a team from Russia FaceOff It was released a long time ago and unfortunately the port was lost and only last year I found it and was able to launch it. 



To install, you need to open the Switch and Renpai folder and extract the NRO file and put it on the SD card. 

To install it you need to go through dbi 
If you don't understand Russian, then unfortunately, you'll have to accept it. I don't understand the engine well, and the port itself is lost.
